# DSHChatMode · 主动聊天

> 让 DeepSeek Harness 里的助手主动开口一次。按你设定的节奏、在你允许的时段、用你自己的人设，发到你选定的会话里。

一个 DeepSeek Harness（DSH）插件：让模型**主动给你发消息**——节奏、时段、话题都由你定，你顺着聊回去，它就正常接着聊。

![DSHChatMode 图标](icon.svg)

## 它做什么

- **按计划冒泡，不是聊天机器人。** 活跃时段内每 10 / 20 / 30 / 60 分钟（或任意自定义间隔）说一句话，附带随机抖动，避免秒表感。
- **你忙的时候它安静。** 工作时段可配置，免打扰（DND）优先于活跃时段；每日次数上限、目标会话正在跑回合时自动延后，都不会硬闯。
- **用你的人设，不用罐头话术。** 每次触发都在目标会话里由模型现场生成，所以灵魂 / 记忆 / AGENTS.md 之类的插件会自然生效；它会先看最近的对话，不重复开场白。
- **发到哪由你定。** 专用会话（第一次投递时创建并一直保留），或绑定到任意已有会话。
- **话题是你会想聊的。** 默认话题池：关心吃喝累不累、八卦、身体睡眠嗓子、天气降温下雨、工作进度搭把手、只发个表情冒泡、想你了 / 无聊——外加一个自由填写的「额外口味」。
- **两种用法。** DSH 客户端里的真实设置页 **设置 → 主动聊天**，或者直接在聊天里说（「每 30 分钟找我一次」「午饭别吵我」）。

## 安装

需要 **DSH ≥ 0.2.2-rc.1**、**Node ≥ 22.12**。

```bash
dsh plugin --profile desktop add dsh-chatmode-plugin
```

也可以在 DSH 里打开 **插件 → 添加插件**，输入 `dsh-chatmode-plugin`，然后重启 DSH。

插件也收录在 Open Plugin Market（索引源 `https://dshopen.org/index.json`），在 **发现** 里加索引后可以直接从市场页安装。

重启后，客户端设置里会多出 **设置 → 主动聊天**。

## 快速开始

1. 打开 **设置 → 主动聊天**（在左侧导航「灵魂」后面）。
2. 打开 **打开主动聊天**，选间隔（10 / 20 / 30 / 60 分钟或自定义），按需调整活跃和免打扰时段。
3. 选 **发送到**：专用会话，或粘贴 / 绑定一个已有会话 id。
4. 点 **保存**，新节奏立即生效；点 **现在跟我说句话** 可以马上试一条。

第一条主动消息不需要你回应什么——在那个会话里正常回它，它就顺着聊下去了。

## 在聊天里指挥它

插件注册了 `chatmode` 工具，所以这些说法都有效：

| 你说 | 它做 |
| --- | --- |
| 「打开主动聊天」 | 打开并按当前设置排期 |
| 「每 30 分钟找我一次」 | 把间隔改成 30 分钟 |
| 「午饭和晚上 11 点后别吵我」 | 改免打扰时段 |
| 「就绑在这个会话里」 | 把当前会话设为投递目标 |
| 「换个专用会话」 | 切回专用会话 |
| 「现在跟我说句话」 | 立刻投递一条 |
| 「主动聊天状态」 | 显示运行状态 |
| 「关掉 / 恢复默认」 | 关闭或全部重置 |

## 工作原理

- 内存里的 30 秒节拍器判断「现在该不该说话」，遵守时段、每日上限和忙闲判断；**没有真正投递时不产生任何模型请求**。
- 投递走 DSH 自己的定时任务服务：一个 2099 年的占位任务持有这个通道，每次触发调用 `schedule.run(taskId)`。这样自动化页面不会被刷屏，目标会话的创建 / 唤醒、工作目录和 agent preset 也都由 DSH 自己处理。
- 插件只在目标会话里注入一段 `## 主动聊天模式` 的系统提示（话题池 + 规则：短句、不提提醒/插件、不调用工具、顺着聊），不会污染其它会话。
- 投递的提醒在界面里折叠成一条「自动化任务」行，不会伪装成用户气泡；看到的是模型的回复。
- 设置存在 `~/.dsh/chatmode/state.json`，改设置**不会**重启插件。

## 设置项

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| enabled | 关 | 总开关 |
| intervalMinutes | 60 | 5–1440 |
| jitterMinutes | 8 | 额外随机 0–N 分钟 |
| maxPingsPerDay | 12 | 1–200 |
| maxMessagesPerPing | 2 | 每次 1–3 条短句 |
| activeWindows | 每天 09:00–22:00 | 留空 = 全天 |
| dndWindows | 12:30–13:30、23:00–08:00 | 优先于活跃时段 |
| topics | 7 个内置话题 | 设置页里一行一个 |
| customInstructions | 空 | 额外口味要求 |
| target | 专用会话 | 或 `session` + 会话 id |

时段是这种 JSON：`{"days":[1,2,3,4,5],"start":"09:00","end":"18:00"}`；`days` 用 ISO 星期（1=周一…7=周日），省略表示每天。支持 `23:00–08:00` 这种跨夜时段。

## 隐私

- 插件自身**不发起任何网络请求**。
- 只读写 `<DSH_HOME>/chatmode/state.json` 和本地滚动日志 `<DSH_HOME>/chatmode/chatmode.log`。
- 设置接口（`/api/chatmode/*`）仅同源可用，每个请求都交给 DSH 自己的 `connection.requestRejection()` 做 Host / 浏览器认证；拿不到该服务时直接拒绝，不降级。
- 不收集、不上传、不分享任何个人数据。

## 限制

- 需要 DSH 客户端在运行（投递依赖桌面端）。
- 最小间隔 5 分钟；调度服务本身还有 60 秒的每任务投递下限。
- **自动化**页里的占位任务由插件管理，不要手动编辑或删除；要停就关开关。
- 目标会话正在跑回合时，这次投递会延后，不会打断。
- 聊天引导提示词默认中文；设置页中英双语。

## 开发

没有构建步骤：宿主侧是纯 ESM，浏览器侧是手写的 `__ModuleLoader__` bundle。

```bash
node --check index.js client.js lib/*.js
node tools/smoke-client.mjs   # 用微型 React stub 渲染设置页做冒烟检查
```

文件：`index.js`（宿主）、`client.js`（设置页）、`lib/settings.js`（时段与排期）、`lib/prompt.js`（提示词）、`lib/web.js`（本地接口）、`locale/*.json`（插件元数据）。
